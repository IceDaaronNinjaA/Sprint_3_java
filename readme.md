# Console RPG

A basic text-based role-playing game written in Java. The player can explore,
fight random enemies, earn gold and experience, level up, rest, and use potions.

## Instructions for Build and Use

Steps to build and/or run the software:

1. get file off of github 
2. complile the code using commands in the terminal or in VS code.
3. run the program

Instructions for using the software:

1. Enter a name for your hero.
2. Choose an action from the main menu.
3. During combat, attack, use a potion, or try to run.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* Java JDK 8 or newer
